#### Taking some notes on PySide6 and how to use it 

Main class : QtWidgets 
=> contains all UI options like buttons, drop down list etc 
=> main class represents a window, child of QtWidgets.QtWidget

Layout : represents multiple widgets like buttons, text areas etc 
=> layout can include another layout 
=> widget : thing we can see on screen 
=> layou : object that arranges other objects

Need to create the layout, create all widgets and add widgets to layout 

Can get amount of widget in a layout with count() function
=> each widget has an index, like first button is 0, second is 1 etc 
=> layout .takeAt(index) : removes the widget, so .takeAt(0) removes the first widget
--> this function returns a layout item object, it's not visible but still exists in memory
--> can mark it for actual deletion with .deleteLater() - will delete safely 

The CBB and other objects have also indexes, can use .count() an range() to iterate through items and make checks
=> getCurrentIndex / setCurrentIndex
